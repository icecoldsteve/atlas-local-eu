# Atlas Local EU

Installable PWA for the European Maps → AI brief → Lovable mockup → Google Business Profile retainer workflow.

US threads sell $60 roofing clicks and inbox blasting. This desk assumes **euros**, **GDPR / ePrivacy**, **DMA-shaped local results**, and trades in Antwerp, Rotterdam, Cologne and Lille — not Austin.

## What you get

- Playbook rewritten for EU niches and Local Pack economics (~40–50% of local-intent clicks)
- Hunt desk: country + city + local-language Google Maps query
- AI desk: copy-ready prompts for **Grok**, **Claude** or **ChatGPT**, plus a Lovable prompt
- Outreach: country rules (DE/FR/AT/IT default opt-in email; NL/BE/ES more flexible B2B)
- Retainer calculator in EUR (€449–€749 bands)
- On-device pipeline (`localStorage` only)

Atlas does not scrape Google, store owner emails on a server, or send messages for you.

## Run

Static files. Open `index.html` or deploy the folder to Vercel.

## Install

Add to Home Screen from a supporting mobile browser. Service worker caches the shell.
